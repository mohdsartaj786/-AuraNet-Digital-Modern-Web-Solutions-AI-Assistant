# 🌌 AuraNet Digital — Modern Web Solutions & AI Assistant

AuraNet Digital is a premium, clean, and fully functional multi-page website built for modern startups and businesses. The entire user interface is inspired by top tech companies like **Stripe and Vercel**, using a beautiful minimalist dark/light design with smooth animations.

---

## ✨ Cool Features inside this Project

*   **🧠 Built-in AI Console Component (`ai-console.html`):** A custom interactive AI assistant box built right into the homepage. Users can type commands like "Startup" or "Growth" to get instant deployment suggestions.
*   **🎨 Premium Design System:** Beautiful glassmorphic effects (blurred backgrounds), clean card layouts, and smooth hover animations that look amazing on both desktop and mobile screens.
*   **🌗 Smart Dark Mode:** Toggle between Dark and Light themes with a single click. The website automatically remembers your preference even if you refresh or close the page.
*   **📊 Live Cost Estimator:** An interactive pricing calculator. Users can drag the range slider or check boxes to see real-time price updates for their projects.
*   **✉️ Working Contact & Modal Forms:** Fully functional lead capturing forms linked directly to a Node.js backend to collect client inquiries safely.

---

## 🛠️ Built With (Tech Stack)

### Front-End
*   **HTML5** - Structured and clean layout.
*   **CSS3** - Custom variables, responsive grids, and smooth transitions.
*   **JavaScript (Vanilla)** - Smooth DOM interactions, calculator logic, and AI response handling.
*   **FontAwesome** - Modern vector icons.

### Back-End
*   **Node.js & Express.js** - Running the server and handling API routing for user data.
